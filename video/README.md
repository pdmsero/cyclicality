# R&D Smoothing explainer video

`rd_smoothing_explainer.mp4` is a narrated, approximately two-minute visual explainer for *R&D Smoothing: Evidence and Some Theory*. It opens with the wave illustration, then features the paper’s firm-level Compustat scatterplot and distinguishes that descriptive fitted relationship (β = 0.239) from the paper’s controlled panel estimates. It closes by connecting the growth-rate result to the countercyclical movements in R&D shares and the model’s smoothing mechanism.

The narrated script is in [`narration.md`](narration.md). The scatter shown is Figure 5, sourced from `paper/figures/Data.jpeg`.
